Beasts and beings from Acromantulas to Thestrals, including the Ministry of Magic's
danger classification.

| | |
| --- | --- |
| **List** | `GET /api/creatures` |
| **Single** | `GET /api/creatures/{slug}` |
| **Records** | 143 |

::alert{type="info" icon="lucide:info"}
Creatures are the one collection **not** sourced from Potter DB, which has no
creatures endpoint. They are compiled from the `Creature infobox` on the
[Harry Potter Fandom wiki](https://harrypotter.fandom.com) instead.
::

## Ministry of Magic classification

| Value | Meaning |

| `XXX` | Competent wizards should cope |

53% of records carry a classification; the rest are `null`.

## Examples

::code-group
```bash [curl]
curl https://hogwarts-api.com/api/creatures/hippogriff
curl "https://hogwarts-api.com/api/creatures?search=dragon"
```

```js [JavaScript]
const res = await fetch('https://hogwarts-api.com/api/creatures?page_size=100');
const { data } = await res.json();

const deadly = data.filter(c => c.classification === 'XXXXX');
console.log('Known wizard killers:', deadly.map(c => c.name).join(', '));
```
