| | |
| --- | --- |

| **Single** | `GET /api/spells/{slug}` |

## Fields

::field-group
  ::field{name="id" type="string" required}
  Same as `slug`.
  ::
  ::field{name="slug" type="string" required}
  URL-safe identifier, e.g. `expecto-patronum`.
  ::
  ::field{name="name" type="string" required}
  Common name, e.g. `Patronus Charm`.
  ::
  ::field{name="incantation" type="string"}
  The words spoken. `null` for non-verbal spells (62% filled).
  ::
  ::field{name="effect" type="string"}
  What the spell does (96% filled).
  ::
  ::field{name="category" type="string"}
  e.g. `Charm`, `Curse`, `Jinx`, `Transfiguration` (99% filled).
  ::
  ::field{name="light" type="string"}
  Colour of the light produced (72% filled).
  ::
  ::field{name="hand" type="string"}
  Wand movement (26% filled).
  ::
  ::field{name="creator" type="string"}
  Who invented it (9% filled).
  ::
  ::field{name="image" type="string"}
  Illustration URL (79% filled).
  ::
  ::field{name="wiki" type="string" required}

## Examples

::code-group
```bash [curl]
curl https://hogwarts-api.com/api/spells/expecto-patronum
curl "https://hogwarts-api.com/api/spells?search=curse"
```

```js [JavaScript]
const res = await fetch('https://hogwarts-api.com/api/spells?page_size=100');
const { data } = await res.json();

const byCategory = data.reduce((acc, spell) => {
  const key = spell.category ?? 'Uncategorised';
  acc[key] = (acc[key] ?? 0) + 1;
  return acc;
}, {});

console.table(byCategory);
```
