::alert{type="info" icon="lucide:info"}
`ingredients` is a single string, not an array — the source stores it as prose. Split
on `, ` if you need a list, but expect the occasional entry with quantities baked in.
::

## Examples

::code-group
```bash [curl]
curl https://hogwarts-api.com/api/potions/polyjuice-potion
curl "https://hogwarts-api.com/api/potions?search=felix"
```

```js [JavaScript]
const res = await fetch('https://hogwarts-api.com/api/potions/polyjuice-potion');
const { data } = await res.json();

console.log(data.name);
console.log('Effect:', data.effect);
console.log('Ingredients:', data.ingredients?.split(', ') ?? 'unknown');
```
