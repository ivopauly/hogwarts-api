All 7 novels by J.K. Rowling, including a full chapter listing for each.

| | |
| --- | --- |
| **List** | `GET /api/books` |
| **Single** | `GET /api/books/{slug}` |
| **Records** | 7 |

## Fields

::field-group
  ::field{name="id" type="string" required}
  Same as `slug`. Stable identifier.
  ::
  ::field{name="slug" type="string" required}
  URL-safe identifier, e.g. `harry-potter-and-the-goblet-of-fire`.
  ::
  ::field{name="title" type="string" required}
  Full published title.
  ::
  ::field{name="summary" type="string" required}
  Blurb describing the plot.
  ::
  ::field{name="author" type="string" required}
  Always `J. K. Rowling`.
  ::
  ::field{name="release_date" type="string" required}
  ISO 8601 date, e.g. `1997-06-26`.
  ::
  ::field{name="dedication" type="string" required}
  The book's printed dedication.
  ::
  ::field{name="pages" type="integer" required}
  Page count of the original edition.
  ::
  ::field{name="cover" type="string" required}
  URL of the cover image.
  ::
  ::field{name="chapters" type="array" required}
  Ordered chapter list. Each entry has `order`, `title` and `summary`.
  ::
  ::field{name="wiki" type="string" required}
  Link to the Fandom wiki article.
  ::
::

::alert{type="warning" icon="lucide:triangle-alert"}
All 199 chapters have an `order` and a `title`, but only 17 currently have a
`summary` — the rest are `null`. Chapter summaries are a
[welcome contribution](https://github.com/ivopauly/hogwarts-api/issues/new/choose).
::

## Examples

::code-group
```bash [curl]
curl https://hogwarts-api.com/api/books
curl https://hogwarts-api.com/api/books/harry-potter-and-the-philosopher-s-stone
curl "https://hogwarts-api.com/api/books?search=azkaban"
```

```js [JavaScript]
const res = await fetch(
  'https://hogwarts-api.com/api/books/harry-potter-and-the-philosopher-s-stone',
);
const { data } = await res.json();

console.log(`${data.title} — ${data.pages} pages`);
data.chapters.forEach(c => console.log(`  ${c.order}. ${c.title}`));
```
::
