The 8 Harry Potter films and 3 Fantastic Beasts films, with credits and box office.

| | |
| --- | --- |
| **List** | `GET /api/movies` |
| **Single** | `GET /api/movies/{slug}` |
| **Records** | 11 |

## Fields

::field-group
  ::field{name="id" type="string" required}
  Same as `slug`.
  ::
  ::field{name="slug" type="string" required}
  URL-safe identifier, e.g. `fantastic-beasts-and-where-to-find-them`.
  ::
  ::field{name="title" type="string" required}
  Full release title.
  ::
  ::field{name="summary" type="string" required}
  Plot synopsis.
  ::
  ::field{name="release_date" type="string" required}
  ISO 8601 date.
  ::
  ::field{name="running_time" type="string" required}
  Runtime, e.g. `152 minutes`.
  ::
  ::field{name="rating" type="string" required}
  MPAA rating, e.g. `PG`, `PG-13`.
  ::
  ::field{name="budget" type="string" required}
  Production budget, as printed — e.g. `$125 million`.
  ::
  ::field{name="box_office" type="string" required}
  Worldwide gross, as printed.
  ::
  ::field{name="directors" type="array" required}
  ::
  ::field{name="screenwriters" type="array"}
  Empty for two of the Fantastic Beasts films.
  ::
  ::field{name="producers" type="array" required}
  ::
  ::field{name="cinematographers" type="array" required}
  ::
  ::field{name="editors" type="array" required}
  ::
  ::field{name="music_composers" type="array" required}
  ::
  ::field{name="distributors" type="array" required}
  ::
  ::field{name="poster" type="string" required}
  URL of the poster image.
  ::
  ::field{name="trailer" type="string" required}
  YouTube URL.
  ::
  ::field{name="wiki" type="string" required}
  ::
::

::alert{type="info" icon="lucide:info"}
`budget` and `box_office` are strings, not numbers — the source records values like
`$175-200 million` that do not fit a numeric type. Parse them if you need arithmetic.
::

## Examples

::code-group
```bash [curl]
curl https://hogwarts-api.com/api/movies
curl https://hogwarts-api.com/api/movies/harry-potter-and-the-prisoner-of-azkaban
curl "https://hogwarts-api.com/api/movies?search=fantastic"
```

```js [JavaScript]
const res = await fetch('https://hogwarts-api.com/api/movies');
const { data } = await res.json();

const byYear = data
  .slice()
  .sort((a, b) => a.release_date.localeCompare(b.release_date));

byYear.forEach(m => console.log(m.release_date, m.title));
```
