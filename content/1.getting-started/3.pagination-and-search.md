Every list endpoint accepts the same three query parameters.

::field-group
  ::field{name="page" type="integer" defaultValue="1"}
  Which page to return. Values past the last page are clamped to the last page.
  ::
  ::field{name="page_size" type="integer" defaultValue="25"}
  How many records per page. Clamped to a maximum of **100**.
  ::
  ::field{name="search" type="string"}
  Case-insensitive substring match on the record's `title` (books, movies) or
  `name` (everything else).
  ::
::

## Reading `meta`

Every list response carries a `meta` object. Use `total_pages` to drive your loop
rather than requesting pages until you get an empty array.

```bash
curl "https://hogwarts-api.com/api/characters?page=2&page_size=5"
```

```json
{
  "data": [ "…5 characters…" ],
  "meta": {
    "page": 2,
    "page_size": 5,
    "total_pages": 1082,
    "total_records": 5410,
    "search": null
  }
}
```

When `search` is active, `total_records` and `total_pages` describe the **filtered**
set, not the whole collection.

## Searching

```bash
curl "https://hogwarts-api.com/api/spells?search=charm"
curl "https://hogwarts-api.com/api/creatures?search=dragon"
curl "https://hogwarts-api.com/api/characters?search=weasley&page_size=100"
```

Search is a plain substring match — `search=weasley` matches "Ginevra Molly Weasley"
because the string appears anywhere in the name. It is not fuzzy, so a typo returns
nothing.

::alert{type="info" icon="lucide:info"}
Search only looks at the name or title. To filter on `house`, `blood_status` or any
other field, fetch the pages you need and filter client-side — see the worked example
in [Quick start](/getting-started/quick-start).
::

## Paging through everything

::code-group
```js [JavaScript]
async function fetchAll(collection) {
  const records = [];
  let page = 1;
  let totalPages = 1;

  do {
    const res = await fetch(
      `https://hogwarts-api.com/api/${collection}?page=${page}&page_size=100`,
    );
    const { data, meta } = await res.json();

    records.push(...data);
    totalPages = meta.total_pages;
    page += 1;
  } while (page <= totalPages);

  return records;
}

const spells = await fetchAll('spells');
```

```python [Python]
import requests

def fetch_all(collection):
    records, page, total_pages = [], 1, 1

    while page <= total_pages:
        res = requests.get(
            f"https://hogwarts-api.com/api/{collection}",
            params={"page": page, "page_size": 100},
        ).json()

        records.extend(res["data"])
        total_pages = res["meta"]["total_pages"]
        page += 1

    return records

spells = fetch_all("spells")
```
::

::alert{type="warning" icon="lucide:triangle-alert"}
`page_size` is capped at 100 on purpose. Asking for `page_size=5000` is not an error —
you will silently get 100 records back, and `meta.page_size` will say `100`. Always
read `meta` rather than assuming you got what you asked for.
::
